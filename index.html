本工具如何即時去 Investing.com 撈取公允價與分析師預估價？

1 即時連線 Investing.com 公開個股頁（免 API Key 直接可用）

當您在左側輸入股票代碼（如 2330、2327、NVDA）時，前端會透過支援 CORS 的 r.jina.ai 瀏覽器渲染代理即時存取 hk.investing.com，直接從網頁中解析出：最新成交價、52 週高低點、12 個月分析師平均目標價、最高/最低預估價、買入/賣出分析師人數、各大外資機構（JPMorgan、摩根士丹利、野村、麥格理等）最新目標價明細表。

2 InvestingPro 公允價快照 & 同業多模型公允價推算

針對公允價值（Fair Value），系統優先載入已驗證的 InvestingPro 公開比較快照數值（或透過選填的 Gemini API Key 即時檢索 site:investing.com/pro 快照）；若個股快照被鎖定，系統會自動根據從 Investing.com 同業比較表撈出的 同業公允價值上升空間 (%)、同業市盈率 (P/E) 與市帳率 (P/B) 即時計算多模型推算公允價區間，並提供一鍵開啟 Google Pro 原始快照連結供您比對驗證。
